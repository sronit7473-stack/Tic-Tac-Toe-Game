Tic Tac Toe Game 🎮

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

Features
Two-player gameplay (X and O)
Winner detection
Draw detection
Reset Game functionality
New Game option
Clean and responsive user interface

Technologies Used
HTML5
CSS3
JavaScript 


How to Play
Player O starts the game.
Players take turns marking the boxes.
The first player to align three identical symbols horizontally, vertically, or diagonally wins.
If all nine boxes are filled and no player wins, the game ends in a draw.
